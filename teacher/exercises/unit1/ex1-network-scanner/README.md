# Exercise 1: Network Scanner and DNS Lookup

Reference solutions:

- `NetworkInterfaceFinal.java`
- `NSLookupFinal.java`

The exercise covers:

- scanning all network interfaces
- printing MAC/IP/interface metadata
- forward and reverse DNS resolution
- `getAllByName()` lookups
- reachability checks with `isReachable()`

Suggested extensions:

- show MTU, index, virtual and point-to-point flags
- display prefix length and broadcast addresses
- accept host/IP input from command-line arguments
- compare multiple DNS results for the same host
